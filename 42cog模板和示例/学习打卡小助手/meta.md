# 项目元信息 (Meta)

## 基本信息

**项目名称**: 学习打卡小助手

**项目标语**: 把每天要学什么、有没有完成、学到了什么记录清楚。

**版本**: 0.1.0

**创建日期**: 2026-07-14

**负责人**: 个人学习者

## 项目描述

学习打卡小助手是一个面向新手的轻量学习记录项目。它帮助用户把长期学习目标拆成每天能完成的小任务，并在完成后记录打卡和一句复盘。

这个项目适合用来理解 `.42cog` 的 meta、cog、real、work 四类文件，因为它的业务足够简单，新手可以直观看懂“项目信息、核心实体、现实约束、工作记录”分别负责什么。

## 目标用户

- 大模型初学者: 正在自学大模型基础知识，需要每天记录学习进度。
- 课程学习者: 跟着课程或训练营学习，需要知道自己每天完成了哪些任务。
- 个人自学者: 想养成稳定学习习惯，但不需要复杂项目管理工具。

## 核心价值主张

1. 让用户每天清楚知道自己要学什么。
2. 用打卡记录帮助用户看到学习是否持续。
3. 用一句复盘沉淀当天最重要的收获。

## 技术栈

**前端**:
- 框架: Next.js 15
- UI: Tailwind CSS
- 语言: TypeScript

**后端**:
- 运行时: Node.js
- 数据存储: 本地 JSON 文件或 SQLite

**基础设施**:
- 本地运行: npm scripts
- 部署: 后续可选 Vercel

**AI集成**:
- 暂不接入 AI
- 后续可扩展为“自动生成学习建议”和“复盘总结”

## 项目里程碑

- [ ] MVP: 可以创建每日任务、完成打卡、填写一句复盘
- [ ] v1.0: 支持学习目标、任务列表、打卡历史
