# 在线教育系统 - 现实约束 (Real)

<real>
- 学员个人信息（姓名、手机号、学习记录）必须加密存储，仅学员本人和授权教师可见
- 课程内容必须经过平台审核后才能发布，直播内容必须实时监控违规内容
- 视频播放必须支持多码率切换，视频缓冲时间必须小于3秒
- 证书必须包含唯一编号且可在官网验证真伪，完成课程且总分≥60分才能获得证书
</real>
